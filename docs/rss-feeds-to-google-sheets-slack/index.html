How to send new items from many RSS feeds to Google Sheets or Slack (with keyword filters)

Updated 2026-10-10 · Tool: RSS Feed Scraper - RSS, Atom & JSON Feed Reader to JSON/CSV · $0.30 per 1,000 feed items; failed feeds, filtered, duplicate and already-seen items are free

Google Sheets' IMPORTFEED handles one feed at a time and breaks easily, and most RSS-to-Slack tools charge per feed. If you follow 30 company blogs, changelogs or industry news sources, you want one deduplicated stream filtered by your keywords.

Here is how to set that up with a scheduled run.

Open the tool on Apify →

Step by step

  1. Paste feed URLs or plain website URLs into feeds (feeds are discovered automatically).
  2. Add keywords and turn on Only new items.
  3. Schedule it hourly or daily and add the Slack or Google Sheets integration.
  4. To get the rows into Google Sheets: download the run's dataset as CSV and import it, or, for automatic updates, add an integration on the actor's Integrations tab (Apify's Google Sheets Import & Export actor, Make, Zapier or n8n) so every finished run appends its rows to your sheet.
  5. Alternatively, in Google Sheets use =IMPORTDATA("https://api.apify.com/v2/acts/tinyrex~rss-feed-scraper/runs/last/dataset/items?format=csv&status=SUCCEEDED&token=YOUR_TOKEN"). Anyone with edit access to the sheet can see the token, so only do this in private sheets (or use a scoped token).
  6. Add a Schedule in Apify (daily or weekly) so the sheet stays fresh.

Example input

{
  "feeds": [
    "https://blog.cloudflare.com/rss/",
    "https://github.com/apify/crawlee/releases.atom",
    "https://www.nasa.gov/feed/"
  ],
  "keywords": [
    "ai",
    "release"
  ],
  "onlyNewItems": true
}

Same thing from the command line (returns CSV directly):

curl -X POST 'https://api.apify.com/v2/acts/tinyrex~rss-feed-scraper/run-sync-get-dataset-items?format=csv' -H 'Authorization: Bearer $APIFY_TOKEN' -H 'Content-Type: application/json' -d '{"feeds": ["https://blog.cloudflare.com/rss/", "https://github.com/apify/crawlee/releases.atom", "https://www.nasa.gov/feed/"], "keywords": ["ai", "release"], "onlyNewItems": true}' > results.csv

FAQ

Can I use any feed?

Technically yes, but check each publisher's terms: some news feeds allow only personal, non-commercial use.

Does it get the full article?

It returns the full text when the feed includes it; it does not open article pages.
