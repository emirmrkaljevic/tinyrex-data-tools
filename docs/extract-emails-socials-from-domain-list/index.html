How to extract emails, phone numbers and social links from a list of company domains

Updated 2026-10-26 · Tool used: Contact Details Extractor - Email, Phone & Social from Website on Apify · Price: about $2 per 1,000 domains with a contact found; domains with no contact, unreachable or blocked hosts are free

You already have the companies (a CRM export, a trade-show list, the output of a tech stack lookup), and now you need a way to reach them: the public info@ or sales@ inbox, a phone number and the LinkedIn company page. Opening 500 websites and hunting for the contact page by hand takes days, and many contact info scrapers charge per page or per result even when nothing is found.

This guide shows how to give a list of domains and get one clean row per company: emails tagged as role/generic (info@, sales@) or personal-looking (first.last@), phones, social profiles, postal addresses and the page each value came from. It reads only the homepage and contact/about/impressum pages on the same host, respects robots.txt and needs no login or browser.

Open Contact Details Extractor on Apify →

Steps

  1. Paste your company domains or URLs into domains (one per line; URLs and duplicates are normalized).
  2. Optionally raise maxPagesPerDomain (default 8) for sites with deep contact pages, and keep respectRobotsTxt on.
  3. Run it, then filter the dataset on hasContact and emails.roleOrGeneric and export as CSV/Excel, or schedule it to refresh contact data monthly.

Run it from code

Python

from apify_client import ApifyClient  # pip install apify-client

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run_input = {
  "domains": [
    "apify.com",
    "example.com"
  ],
  "maxPagesPerDomain": 8,
  "respectRobotsTxt": true
}
run = client.actor("tinyrex/contact-details-extractor").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript / Node.js

import { ApifyClient } from 'apify-client'; // npm i apify-client

  ],

  "respectRobotsTxt": true
});
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

FAQ

Is this an alternative to the popular contact info scrapers?

Yes, for the common case where you already know the company websites. It does not crawl search engines or directories; it visits only the homepage and contact-looking pages of each domain you give it, which keeps it fast and cheap. You pay about $0.002 per domain where at least one contact was found, and nothing for domains without contacts or that fail.

How do I find the email address of a company from its website?

Most companies publish a role inbox (info@, hello@, sales@) on the homepage footer, contact page or impressum. The actor collects every mailto link and on-page address from those pages and flags which ones are role/generic, so you can pick the right inbox per company.

Can I get the LinkedIn company page for a list of domains?

Yes. Social links the company itself puts on its site (LinkedIn, X/Twitter, Facebook, Instagram, YouTube, GitHub, TikTok) are returned in the socials object, one column per network in the CSV export.

Is it GDPR compliant?

Emails and phone numbers can be personal data. You decide the purpose and act as the controller; the personalLooking flag helps you keep only role/generic addresses for outreach. Check the email-marketing rules of each recipient's country before contacting anyone.
