How to get Dutch public tenders from TenderNed into a spreadsheet, with daily alerts

Updated 2026-10-28 · Tool used: TenderNed Netherlands Tenders Scraper on Apify · Price: $2.50 per 1,000 notices; failed and empty runs and notices already seen are free

TenderNed is the national procurement platform of the Netherlands. Every Dutch public buyer publishes its notices there, including many contracts below the EU threshold that never appear on TED. The website search works for one person, but bid teams that track several keywords end up copying notices into a sheet by hand.

This guide shows how to pull TenderNed notices from the official keyless open data API (CC0) into CSV, Excel or JSON, filter them by keyword, publication date, assignment type and open deadline, and run the search every morning so you only see notices that are new since the last run.

Open TenderNed Netherlands Tenders Scraper on Apify →

Steps

  1. Add search terms to keywords (Dutch or English, e.g. software, ICT, schoonmaak) or leave it empty for every notice in the date window.
  2. Set publishedWithinDays or an exact publishedFrom/publishedTo range, and turn on onlyOpen to drop notices whose deadline has passed.
  3. Schedule it daily with onlyNew on and a stateKey per saved search; each run then returns only new notices, and already-seen ones are free.

Every run's dataset can be downloaded as JSON, CSV, Excel, XML or HTML from the Apify Console, or via https://api.apify.com/v2/datasets/<datasetId>/items?format=csv.

Run it from code

Python

from apify_client import ApifyClient  # pip install apify-client

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run_input = {
  "keywords": [
    "software"
  ],
  "publishedWithinDays": 14,
  "maxResults": 20,
  "onlyOpen": true
}
run = client.actor("tinyrex/tenderned-tenders-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

FAQ

Is there a free TenderNed API?

Yes. TenderNed publishes its notices as open data under CC0 through a public JSON API with no key. The actor reads that API, so you get the same data as the website.

Does it include tenders below the EU threshold?

Yes. National notices that are only published on TenderNed are included, which is the main reason to use it next to TED.

Can I get the CPV code and region of each tender?

Yes, with includeDetails on (the default) each notice is enriched with its CPV code and NUTS place of performance. Turn it off for a faster run without those fields.

Can I filter by works, supplies or services?

Set typeOpdracht to W (works), L (supplies) or D (services).
