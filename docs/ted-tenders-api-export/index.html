How to export EU public tenders from TED (Tenders Electronic Daily) to CSV or JSON

Updated 2026-10-09 · Tool used: TED EU Tenders Scraper - Public Procurement & Awards on Apify · Price: $2.50 per 1,000 notices; already-seen notices in alert mode are free

TED (ted.europa.eu) publishes every EU/EEA public tender above the EU thresholds, but its search UI is slow for repeat work and its API returns deeply nested eForms data that is hard to use in a spreadsheet.

This guide shows how to export tenders by CPV codes, countries and dates to flat CSV/JSON rows (buyer, CPV, deadline, value, winners, links to the PDF and documents), and how to turn it into a daily tender alert.

Open TED EU Tenders Scraper on Apify →

Steps

  1. Pick CPV codes (e.g. 72000000 IT services) and buyer countries, or use keywords.
  2. Set publishedWithinDays, noticeCategories (competition/result/planning) and onlyOpen.
  3. Schedule daily with Only new notices on and connect it to email, Slack or a Google Sheet.

Every run's dataset can be downloaded as JSON, CSV, Excel, XML or HTML from the Apify Console, or via https://api.apify.com/v2/datasets/<datasetId>/items?format=csv.

Run it from code

Python

from apify_client import ApifyClient  # pip install apify-client

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run_input = {
  "cpvCodes": [
    "72000000",
    "48000000"
  ],
  "countries": [
    "DE",
    "AT"
  ],
  "publishedWithinDays": 7,
  "noticeCategories": [
    "competition"
  ],
  "onlyOpen": true,
  "maxResults": 200
}
run = client.actor("tinyrex/ted-tenders-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

curl (no SDK)

# Runs the actor and returns the results directly (CSV here; use format=json for JSON)
curl -X POST "https://api.apify.com/v2/acts/tinyrex~ted-tenders-scraper/run-sync-get-dataset-items?format=csv" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"cpvCodes": ["72000000", "48000000"], "countries": ["DE", "AT"], "publishedWithinDays": 7, "noticeCategories": ["competition"], "onlyOpen": true, "maxResults": 200}' > results.csv

FAQ

Is there an official TED API?

Yes, the TED Search API (api.ted.europa.eu). The actor uses it, so there is no HTML scraping and no blocking, and flattens the results for you.

Can I get contract award winners?

Yes. Use noticeCategories: ["result"] to get awarded values, winners and award dates.

How do I get daily tender alerts?

Enable the only-new-notices option and create an Apify schedule; each run returns only notices you have not seen before.
