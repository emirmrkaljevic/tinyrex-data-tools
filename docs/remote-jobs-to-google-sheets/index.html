How to get remote job listings from 5 job boards into one spreadsheet

Updated 2026-10-10 · Tool: Remote Jobs Scraper - Himalayas, Remote OK, We Work Remotely · $0.80 per 1,000 jobs with full descriptions; filtered-out, duplicate and already-seen jobs are free

Job seekers, recruiters and job board owners all end up checking the same five remote job boards every day. A single deduplicated table with title, company, salary, location restrictions and the full description saves that time and makes filtering easy.

The data comes from the boards' official public APIs and RSS feeds.

Open the tool on Apify →

Step by step

  1. Open the Remote Jobs Scraper, add keywords (or leave empty for everything) and pick the boards.
  2. Turn on the option for only new jobs if you schedule it daily.
  3. To get the rows into Google Sheets: download the run's dataset as CSV and import it, or, for automatic updates, add an integration on the actor's Integrations tab (Apify's Google Sheets Import & Export actor, Make, Zapier or n8n) so every finished run appends its rows to your sheet.
  4. Alternatively, in Google Sheets use =IMPORTDATA("https://api.apify.com/v2/acts/tinyrex~remote-jobs-scraper/runs/last/dataset/items?format=csv&status=SUCCEEDED&token=YOUR_TOKEN"). Anyone with edit access to the sheet can see the token, so only do this in private sheets (or use a scoped token).
  5. Add a Schedule in Apify (daily or weekly) so the sheet stays fresh.

Example input

{
  "keywords": [
    "python",
    "data engineer"
  ],
  "maxResultsPerSearch": 300,
  "onlyNewJobs": true
}

Same thing from the command line (returns CSV directly):

curl -X POST 'https://api.apify.com/v2/acts/tinyrex~remote-jobs-scraper/run-sync-get-dataset-items?format=csv' -H 'Authorization: Bearer $APIFY_TOKEN' -H 'Content-Type: application/json' -d '{"keywords": ["python", "data engineer"], "maxResultsPerSearch": 300, "onlyNewJobs": true}' > results.csv

FAQ

Are duplicates removed?

Yes, the same job posted on several boards appears once.

Do I get salaries?

When the board publishes them, yes, as min/max/currency columns.
