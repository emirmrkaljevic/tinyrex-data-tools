How to take bulk website screenshots from a URL list and save them to CSV or Google Drive

Updated 2026-10-25 · Tool used: Bulk Website Screenshot - Full Page PNG/JPEG from URL List on Apify · Price: $0.002 per saved screenshot ($2 per 1,000), no compute fees on top; unreachable pages, timeouts and HTTP errors are free

Agencies archiving client pages before a redesign, SEO teams documenting a migration, and sales teams adding a homepage thumbnail to every lead all need the same thing: a screenshot of each page in a list. Browser extensions do one tab at a time, and many screenshot APIs bill every request, including the ones that time out or return a 404.

This guide shows how to paste a list of URLs (or a whole sitemap), get one PNG or JPEG per page in a single run, and end up with a CSV where every row has the status code, page title, final URL after redirects and a direct screenshotUrl. It also shows how to move the images into Google Drive automatically, so they outlive the run storage.

Steps

  1. Paste your pages into urls, one per line. Bare domains like example.com work, and duplicates are removed. To capture a whole site, run the Sitemap Scraper first and feed its url column in.
  2. Choose fullPage (scrolls once so lazy images load, capped at maxFullPageHeight), a device (desktop, laptop, tablet, mobile or custom) and png or the 3-10x smaller jpeg.
  3. Run it and export the dataset as CSV or Excel: one row per URL with statusCode, title, screenshotUrl and error. Failed rows are listed but not charged.
  4. To keep the files in Google Drive, add a Make, Zapier or n8n scenario on the actor's Integrations tab that runs on success, downloads each screenshotUrl and uploads it to a Drive folder (the same works for Dropbox or S3). Images in run storage expire with your plan's retention (7 days on the free plan).
  5. For dated archives or before/after comparisons, save the input as a task and add a daily or weekly Schedule.

Run it from code

Python

from apify_client import ApifyClient  # pip install apify-client

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run_input = {
  "urls": [
    "https://example.com",
    "https://apify.com"
  ],
  "fullPage": true,
  "device": "desktop",
  "format": "jpeg",
  "jpegQuality": 80,
  "hideCookieBanners": true
}
run = client.actor("tinyrex/bulk-website-screenshot").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

FAQ

How do I take screenshots of a list of URLs at once?

Paste the list into urls and run. Pages are captured three at a time by default in headless Chromium, and every URL gets a dataset row with its image link or the reason it failed. A few hundred pages usually finish in minutes.

How do I save website screenshots to Google Drive?

Each dataset row has a public screenshotUrl. Connect the actor's run-succeeded event to Make, Zapier or n8n, download every image from that column and upload it to a Drive folder. If you only need the links, export the dataset as CSV and import it into Google Sheets; the screenshotUrl column opens each image.

Can I get full-page and mobile screenshots?

Yes. Turn on fullPage for the whole scrollable page (default cap 10,000 px, up to 30,000) and set device to mobile (390x844 at 2x with a mobile user agent) or tablet. Run twice with different devices to get both versions of each page.

What does it cost, and are failed pages charged?

$0.002 per saved screenshot, which is $2 per 1,000, with platform usage already included. DNS errors, refused connections, timeouts, file downloads and pages that answer with HTTP 4xx or 5xx are free because no image is saved.

Does it remove cookie banners?

Common consent popups (OneTrust, Cookiebot, Didomi, Quantcast, Usercentrics, TrustArc and generic cookie bars) are hidden with CSS; nothing is clicked or accepted. Add extra selectors in hideSelectors for chat widgets or promo bars. Pages behind a login, paywall or CAPTCHA can't be captured.
