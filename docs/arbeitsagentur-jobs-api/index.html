How to export jobs from the Bundesagentur für Arbeit (Arbeitsagentur) and EURES

Updated 2026-10-08 · Tool used: Arbeitsagentur Jobs Scraper - Germany, Austria, CH & EURES on Apify · Price: $1 per 1,000 jobs with full descriptions

The Bundesagentur für Arbeit runs Germany's largest job database (over a million listings) and has a public Jobsuche API, but it needs specific headers, paging and a separate call per job for the description. EURES adds vacancies from Austria (AMS), Switzerland and the rest of the EU in a different format.

This guide shows how to search both by keyword and location and get one normalized dataset with full descriptions, salary (when published), postal code, coordinates, working time and contract type.

Open Arbeitsagentur Jobs Scraper on Apify →

Steps

  1. Enter keywords (e.g. Elektriker, Data Analyst) and pick sources.
  2. Set Arbeitsagentur locations and radius, and EURES country codes (at, ch...).
  3. Export to CSV/JSON, or schedule with publishedWithinDays for a daily feed of new jobs.

Every run's dataset can be downloaded as JSON, CSV, Excel, XML or HTML from the Apify Console, or via https://api.apify.com/v2/datasets/<datasetId>/items?format=csv.

Run it from code

Python

from apify_client import ApifyClient  # pip install apify-client

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run_input = {
  "keywords": [
    "Data Analyst",
    "Elektriker"
  ],
  "sources": [
    "arbeitsagentur",
    "eures"
  ],
  "baLocations": [
    "Berlin",
    "München"
  ],
  "baRadiusKm": 25,
  "euresLocations": [
    "at",
    "ch"
  ],
  "publishedWithinDays": 7,
  "maxResultsPerSearch": 200
}
run = client.actor("tinyrex/dach-jobs-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

curl (no SDK)

# Runs the actor and returns the results directly (CSV here; use format=json for JSON)
curl -X POST "https://api.apify.com/v2/acts/tinyrex~dach-jobs-scraper/run-sync-get-dataset-items?format=csv" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"keywords": ["Data Analyst", "Elektriker"], "sources": ["arbeitsagentur", "eures"], "baLocations": ["Berlin", "München"], "baRadiusKm": 25, "euresLocations": ["at", "ch"], "publishedWithinDays": 7, "maxResultsPerSearch": 200}' > results.csv

FAQ

Does the Arbeitsagentur have an official jobs API?

Yes, the public Jobsuche API that powers arbeitsagentur.de. The actor uses it (and the EURES public search), so results match the official portals.

Can I get jobs in Austria and Switzerland?

Yes, through EURES, which aggregates vacancies from the AMS and other European public employment services.

Are full descriptions included?

Yes, at the same price of $1 per 1,000 jobs.
