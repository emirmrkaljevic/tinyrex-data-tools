How to export open EU funding calls (Horizon Europe, Digital Europe, cascade funding) to CSV or JSON

Updated 2026-10-08 · Tool used: EU Grants Scraper - Horizon Europe & EU Funding Calls on Apify · Price: $3 per 1,000 funding calls; filtered-out and already-seen calls are free

The EU Funding & Tenders Portal lists every Horizon Europe, Digital Europe, LIFE, Erasmus+ and CEF topic, but its search UI is slow for repeat work, exports are limited, and many calls flagged as open or forthcoming have deadlines that already passed (more than half in our tests).

This guide shows how to export calls by programme, keyword and deadline window into flat rows (identifier, title, programme, opening date, deadlines, budget, expected grants, EU contribution per project, type of action, link), with the real status computed from the dates, and how to turn it into a weekly funding alert.

Open EU Grants Scraper on Apify →

Steps

  1. Pick programmes (e.g. HORIZON, DIGITAL) or leave empty for all, and add keywords such as artificial intelligence.
  2. Keep the default statuses (open + forthcoming) and optionally set deadlineTo.
  3. Schedule it weekly with Only new calls on and send new calls to email, Slack or a Google Sheet.

Run it from code

Python

from apify_client import ApifyClient  # pip install apify-client

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run_input = {
  "programmes": [
    "HORIZON",
    "DIGITAL"
  ],
  "keywords": [
    "artificial intelligence",
    "robotics"
  ],
  "statuses": [
    "open",
    "forthcoming"
  ],
  "deadlineTo": "2027-06-30",
  "maxResults": 200
}
run = client.actor("tinyrex/eu-grants-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

curl (no SDK)

# Runs the actor and returns the results directly (CSV here; use format=json for JSON)
curl -X POST "https://api.apify.com/v2/acts/tinyrex~eu-grants-scraper/run-sync-get-dataset-items?format=csv" \

FAQ

Does the EU Funding & Tenders Portal have an API?

Yes, the portal's own search API. The actor uses it (no HTML scraping) and flattens budgets and deadlines into simple columns.

Why does the portal show expired calls as open?

Status flags on the portal are often not updated. The actor computes status from the opening date and deadlines and keeps the portal's flag as portalStatus.

What is cascade funding?

EU-funded projects re-grant part of their budget through their own open calls, often EUR 10k to 500k for SMEs and startups. These calls are included.
