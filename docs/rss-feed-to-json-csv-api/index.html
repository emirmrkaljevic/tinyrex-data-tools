How to turn any RSS or Atom feed into JSON or CSV (bulk, with monitoring)

Updated 2026-10-09 · Tool used: RSS Feed Scraper - RSS, Atom & JSON Feed Reader to JSON/CSV on Apify · Price: $0.30 per 1,000 feed items; failed feeds, filtered, duplicate and already-seen items are free

RSS and Atom are still the cheapest way to follow news sites, blogs, podcasts, YouTube channels and changelogs, but every feed is slightly different: RSS 2.0, RDF, Atom, JSON Feed, HTML inside descriptions, emails in author fields, missing dates. Most online RSS-to-JSON converters handle one feed at a time.

This guide shows how to read hundreds of feeds in one run (or just paste website URLs and let the feeds be discovered), get one normalized row per item (title, link, publish date, author, summary, full text, image, categories, enclosure), filter by keywords and date, and receive only new items on a schedule.

Open RSS Feed Scraper on Apify →

Steps

  1. Add feeds: feed URLs or plain website URLs (the actor finds their feeds).
  2. Optionally set keywords, excludeKeywords and publishedWithinDays.
  3. Schedule it with Only new items on and send new items to Slack, email, a Google Sheet or an LLM summary.

Run it from code

Python

from apify_client import ApifyClient  # pip install apify-client

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run_input = {
  "feeds": [
    "https://www.nasa.gov/feed/",
    "blog.cloudflare.com",
    "https://github.com/apify/crawlee/releases.atom"
  ],
  "keywords": [
    "ai",
    "openai",
    "nvidia"
  ],
  "publishedWithinDays": 2,
  "maxItemsPerFeed": 50,
  "includeContent": true
}
run = client.actor("tinyrex/rss-feed-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

curl (no SDK)

# Runs the actor and returns the results directly (CSV here; use format=json for JSON)
curl -X POST "https://api.apify.com/v2/acts/tinyrex~rss-feed-scraper/run-sync-get-dataset-items?format=csv" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"feeds": ["https://www.nasa.gov/feed/", "blog.cloudflare.com", "https://github.com/apify/crawlee/releases.atom"], "keywords": ["ai", "openai", "nvidia"], "publishedWithinDays": 2, "maxItemsPerFeed": 50, "includeContent": true}' > results.csv

FAQ

Can I convert RSS to JSON for free?

Apify's free plan includes monthly platform credit, which covers thousands of feed items at $0.30 per 1,000. Feeds that fail are not charged.

Does it find the feed if I only have the website?

Yes. It reads the site's feed links and tries the common feed paths (/feed, /rss, /atom.xml and others).

Does it work for podcasts and YouTube?

Yes. Podcast enclosures (audio URL, length, type, duration) and YouTube channel feeds are supported.
