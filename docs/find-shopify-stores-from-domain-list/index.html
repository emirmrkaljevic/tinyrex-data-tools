How to find which websites in a list use Shopify, WooCommerce or HubSpot

Updated 2026-10-09 · Tool: Tech Stack Detector - Bulk Wappalyzer & BuiltWith Alternative · about $4 per 1,000 analyzed domains; unreachable, blocked and timed-out domains are free

Agencies, app developers and SaaS sales teams often have a list of domains (from a CRM, a trade show, a directory) and need to know which of them run on a specific platform. Opening each site with a browser extension does not scale.

A bulk technology lookup answers it in minutes: give it the list, tell it which technology you care about, and keep only the matches.

Open the tool on Apify →

Step by step

  1. Paste your domains into domains (URLs and duplicates are cleaned up automatically).
  2. Set onlyIfUses to ["Shopify"] (or WooCommerce, HubSpot, Klaviyo...). Non-matching domains are not saved.
  3. To get the rows into Google Sheets: download the run's dataset as CSV and import it, or, for automatic updates, add an integration on the actor's Integrations tab (Apify's Google Sheets Import & Export actor, Make, Zapier or n8n) so every finished run appends its rows to your sheet.
  4. Alternatively, in Google Sheets use =IMPORTDATA("https://api.apify.com/v2/acts/tinyrex~tech-stack-detector/runs/last/dataset/items?format=csv&status=SUCCEEDED&token=YOUR_TOKEN"). Anyone with edit access to the sheet can see the token, so only do this in private sheets (or use a scoped token).
  5. Add a Schedule in Apify (daily or weekly) so the sheet stays fresh.

Example input

{
  "domains": [
    "allbirds.com",
    "gymshark.com",
    "wordpress.org",
    "example.com"
  ],
  "onlyIfUses": [
    "Shopify"
  ]
}

Same thing from the command line (returns CSV directly):

curl -X POST 'https://api.apify.com/v2/acts/tinyrex~tech-stack-detector/run-sync-get-dataset-items?format=csv' -H 'Authorization: Bearer $APIFY_TOKEN' -H 'Content-Type: application/json' -d '{"domains": ["allbirds.com", "gymshark.com", "wordpress.org", "example.com"], "onlyIfUses": ["Shopify"]}' > results.csv

FAQ

How accurate is it?

It uses an open-source Wappalyzer-compatible fingerprint database and checks the HTML, headers, cookies and scripts of each homepage. Platforms like Shopify and WooCommerce are detected very reliably.

What does it cost?

About $4 per 1,000 analyzed domains; unreachable domains are free.
