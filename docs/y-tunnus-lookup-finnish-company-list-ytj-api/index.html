How to look up Finnish companies by Y-tunnus and build B2B lead lists from the YTJ register

Updated 2026-10-26 · Tool used: Finland Company Search - Y-tunnus Lookup & B2B Leads (YTJ/PRH) on Apify · Price: $0.001 per company ($1 per 1,000); invalid business IDs, no-match searches, duplicates and filtered rows are free

Every Finnish company has a business ID (Y-tunnus) in YTJ, the business information system run by the Finnish Patent and Registration Office (PRH) and the Tax Administration. It tells you the official name, company form, main line of business, addresses, website, registration date and whether the company is in the VAT, employer and prepayment registers or in bankruptcy or liquidation.

This guide shows how to read the YTJ open data API in bulk: enrich a CRM list of business IDs, match names to business IDs, or build a lead list such as "IT companies in Tampere and Oulu that are VAT-registered employers with a website" or "every new limited company registered this month". No API key or login is needed.

Open Finland Company Search on Apify →

Steps

  1. For lookups, paste business IDs or names into companies. 0112038-9, 01120389 and the VAT form FI01120389 all work, and the check digit is validated first, so typos come back as free rows.
  2. For a lead list, leave companies empty and set industryCodes (TOL prefixes, e.g. 62 for IT), cities (Finnish post office names), postal codes, companyForms (e.g. OY) and registeredFrom, with a maxResults cap.
  3. Turn on vatRegisteredOnly, employerOnly or withWebsiteOnly to keep only real, active businesses. Skipped rows are free.
  4. Run it and export the dataset as CSV or Excel. For a weekly feed of new companies, save the input as a task with registeredFrom and add a Schedule.

Run it from code

Python

from apify_client import ApifyClient  # pip install apify-client

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run_input = {
  "companies": [
    "0112038-9",
    "FI23365096",
    "Kone"
  ]
}
run = client.actor("tinyrex/finland-company-search").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript / Node.js

FAQ

Is there a free API for Finnish company data?

Yes. PRH publishes the YTJ open data API with no key, under the Creative Commons Attribution 4.0 licence, which allows commercial reuse with attribution. This actor calls it politely and returns flat rows.

How do I get a list of all companies in a Finnish industry or city?

Set industryCodes and cities and run without companies. Only the company's main line of business counts, and matchTotal shows the full count of a search for market sizing.

Does it include emails or phone numbers?

No. The public register has no emails, phones, employee counts or financial statements. Many companies list a website, so you can pass those websites to a contact extractor.

What does it cost?

$0.001 per company returned ($1 per 1,000). Invalid business IDs, names with no match, duplicates and rows skipped by your filters are not charged.
