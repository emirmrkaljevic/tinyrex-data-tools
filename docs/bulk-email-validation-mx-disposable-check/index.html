How to clean an email list before a campaign: bulk MX, disposable and typo check

Updated 2026-10-27 · Tool used: Bulk Email Validator - MX, Disposable, Role & Typo Check on Apify · Price: $0.30 per 1,000 emails; bad syntax, duplicates and DNS errors are free

Old CRM exports, scraped lead lists and signup forms all collect dead domains, typos like gmial.com and throwaway inboxes. Sending to them causes bounces that hurt your sender reputation, and most verification services charge several dollars per 1,000 addresses.

This guide shows how to run a cheap first pass over thousands of addresses using DNS only: syntax, whether the domain exists and accepts mail (MX, null MX, A fallback), about 10,000 disposable domains, role inboxes such as info@, free webmail and typo suggestions, plus the domain's SPF and DMARC. It does not probe mailboxes over SMTP, which keeps it fast and safe for your list.

Open Bulk Email Validator on Apify →

Steps

  1. Paste addresses into emails (a column copied from Excel or a CRM export works), or set datasetId to pull every email from another run, such as a contact extractor.
  2. Run it. Each unique address that gets a DNS verdict is one charge; duplicates and bad syntax are free.
  3. Filter by status and flags such as isRoleBased or isDisposable, then export only the valid rows as CSV.

FAQ

How do I check if an email is valid without sending an email?

The actor checks the syntax and asks DNS whether the domain exists and has a mail server. If either fails, the address cannot receive mail and is marked invalid.

Does it check whether the mailbox exists?

No. There is no SMTP handshake, so it cannot confirm that a specific person's mailbox exists on a domain that accepts mail. Use it to remove dead domains, disposables and typos first, then send the rest to an SMTP verifier if you need mailbox-level certainty.

Should I remove role-based emails like info@?

For cold outreach to people, often yes; for B2B lead lists they are usually fine. They stay valid and are flagged with isRoleBased so you can decide.

Is my list stored or shared?

The emails stay in your own Apify run storage. Lookups go to public DNS over HTTPS, which only sees domain names, never full addresses.
