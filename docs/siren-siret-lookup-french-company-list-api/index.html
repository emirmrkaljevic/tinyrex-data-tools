How to look up French companies by SIREN or SIRET and build a B2B list from Sirene

Updated 2026-10-28 · Tool used: France Company Search - SIREN, SIRET & B2B Lists (Sirene) on Apify · Price: $0.0015 per company ($1.50 per 1,000); invalid numbers, no-match searches and duplicates are free

Checking a French supplier, enriching a CRM export of SIREN numbers or sizing a market ("how many software companies with 10 to 50 staff are there in Lyon?") all need the same data: the official company register. The public directory site shows one company at a time, the raw Sirene files are several gigabytes, and paid French company databases charge a subscription.

This guide shows how to use the French government's free company search API (API Recherche d'entreprises, the service behind annuaire-entreprises.data.gouv.fr, built on INSEE Sirene and the national business register) to get one clean row per company: name, SIREN and head-office SIRET, NAF code and label, legal form, size category, employee band, address with coordinates, intra-EU VAT number, latest published revenue and net income, and optionally directors. No API key or login is needed.

Open France Company Search on Apify →

Steps

  1. For lookups, paste SIREN (9 digits), SIRET (14 digits), French VAT numbers (FR + 11 digits) or company names into companies, one per line. Check digits are validated first, so typos come back as free rows instead of wrong companies.
  2. For a B2B list, leave companies empty and set filters instead: nafCodes (e.g. 62.01Z software), departments (e.g. 69), postalCodes, employeeRanges or companyCategories, plus optional free text in searchQuery and a maxResults cap.
  3. Keep activeOnly on to skip ceased companies, and turn includeDirectors on if you need officers (name and role only, no birth dates).
  4. Run it and export the dataset as CSV or Excel. Each row also links to the company's public Annuaire des Entreprises page. Add a Schedule to refresh the list monthly.

Run it from code

Python

from apify_client import ApifyClient  # pip install apify-client

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run_input = {
  "companies": [
    "552032534",
    "Michelin"
  ],
  "maxResultsPerName": 1,
  "preferLargest": true,
  "includeDirectors": false
}
run = client.actor("tinyrex/france-company-search").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

FAQ

Is there a free API for SIREN and SIRET lookups?

Yes. The French government (DINUM) runs API Recherche d'entreprises, which needs no key and combines INSEE Sirene with the national business register (RNE). This actor calls it for you, validates the numbers and returns flat rows ready for a spreadsheet.

How do I get a list of all companies in France with a given NAF code?

Put the NAF/APE code into nafCodes and narrow it with departments or postalCodes. The API serves at most 10,000 companies per search, so for a nationwide list run one department at a time.

Can I reuse the data commercially?

The data is open data under the Licence Ouverte / Open Licence 2.0, which allows commercial reuse with attribution ("Source: Annuaire des Entreprises / Sirene, INSEE"). Companies that opted out of public listing are not in the API. Director names are personal data, so check your GDPR legal basis before using them for outreach.

What does it cost?

$0.0015 per company returned ($1.50 per 1,000). Invalid SIREN/SIRET numbers, names with no match and duplicates are listed with the reason but not charged.
