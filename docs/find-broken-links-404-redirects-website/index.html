How to find every broken link and redirect on a website, with the pages to fix

Updated 2026-10-28 · Tool used: Broken Link Checker - Find 404s, Dead Links & Redirects on Apify · Price: about $0.50 per 1,000 unique links checked; each URL is checked once however many pages link to it

Broken links frustrate visitors and waste crawl budget, and they pile up quietly: a partner site goes offline, a product page is deleted, an image is renamed after a redesign. Free online checkers usually stop after a few hundred links or show the dead URL without telling you which page links to it.

This guide shows how to crawl one or many websites and get a ranked list of problem links: broken (4xx/5xx), unreachable (DNS, timeout, TLS) and blocked by bot protection, plus every redirect with its chain and final URL. Each row says on which pages the link appears and with what anchor text, so you know exactly what to edit.

Open Broken Link Checker on Apify →

Steps

  1. Put one or more homepages in startUrls and set maxPagesPerSite for how deep the crawl goes.
  2. Choose whether to check external links and assets (checkExternalLinks, checkAssets) and set maxLinksToCheck as a cost cap.
  3. Export the dataset as CSV, sort by foundOnCount and fix the links used on the most pages first; the SUMMARY record has per-site totals.

{
  "startUrls": [
    "https://quotes.toscrape.com"

  "maxPagesPerSite": 50,
  "maxLinksToCheck": 500

Run it from code

Python

from apify_client import ApifyClient  # pip install apify-client

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run_input = {
  "startUrls": [
    "https://quotes.toscrape.com"
  ],
  "maxPagesPerSite": 50,
  "maxLinksToCheck": 500
}
run = client.actor("tinyrex/broken-link-checker").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

FAQ

How do I find all broken links on my website?

Enter the homepage and run it. The actor crawls internal pages, collects every link and asset and checks each unique URL once. Rows with status broken or error are the ones to fix.

Why are LinkedIn or some other links marked blocked?

Sites with bot protection answer 401, 403, 429 or 999 to automated requests even when the page exists. Those links are reported as blocked, separate from truly broken ones, so you can check them by hand.

Does it report redirects?

Yes. By default every redirect is listed with its full redirectChain, redirectCount and finalUrl. Set reportMode to problems if you do not need them.

What is the difference to the sitemap broken link check?

The sitemap check tests only the URLs listed in your sitemaps. This actor crawls the pages and tests the links inside them, including images, scripts and external links.
