How to export US federal (SAM.gov) and UK (Contracts Finder) tenders to CSV or JSON

Updated 2026-10-28 · Tool used: SAM.gov & UK Contracts Finder Tenders Scraper on Apify · Price: $2.50 per 1,000 notices; empty or failed runs and notices skipped as already seen are free

SAM.gov lists every US federal contract opportunity and Contracts Finder lists UK public sector contracts above the publishing thresholds, but both websites are built for browsing one notice at a time, and their search pages don't give you a clean export or alerts with your own filters.

This guide shows how to pull both through their official APIs (SAM.gov Get Opportunities Public API and the Contracts Finder OCDS search under the Open Government Licence) into one table with the same columns: title, buyer, publication and deadline dates, open/closed flag, estimated value and currency, NAICS or CPV code, procedure and notice type, and a direct notice URL.

Open SAM.gov & UK Contracts Finder Tenders Scraper on Apify →

Steps

  1. Pick sources: contracts-finder needs no key; sam.gov needs a free public API key from your SAM.gov Account Details page, pasted into samApiKey.
  2. Add keywords (matched against titles, and UK descriptions), a publishedWithinDays window and maxResults. For SAM.gov you can also filter by samNaicsCode, samState and procurement type; for the UK by stage (planning, tender, award).
  3. Run it and export the dataset as CSV or Excel, or turn on onlyNew with a stateKey and schedule it daily for an alert feed of new notices only.

FAQ

Is there an API for SAM.gov contract opportunities?

Yes. GSA publishes the Get Opportunities Public API; you need a free public API key from your SAM.gov account. The actor calls that API with your key, so you get the same notices as the website, as clean rows.

Does UK Contracts Finder have an API?

Yes. Contracts Finder offers an OCDS (Open Contracting Data Standard) notice search that needs no key. Its data is published under the Open Government Licence v3.0, which allows commercial reuse with attribution.

How do I get alerts for new government tenders?

Turn on onlyNew, give each saved search its own stateKey and add a daily Schedule. Each run returns only notices it has not returned before, and the skipped ones are free. Send the rows to Google Sheets, email or Slack from the Integrations tab.

What does it cost?

$0.0025 per notice ($2.50 per 1,000). A run that finds nothing, fails, or only sees notices it already returned costs only the tiny start fee.
