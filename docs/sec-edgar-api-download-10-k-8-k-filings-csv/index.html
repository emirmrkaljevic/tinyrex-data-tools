How to download SEC filings (10-K, 10-Q, 8-K, Form 4) by ticker and search EDGAR full text

Updated 2026-10-28 · Tool used: SEC EDGAR Filings Scraper - 10-K, 10-Q, 8-K by Ticker on Apify · Price: $0.0005 per filing ($0.50 per 1,000); unknown tickers, companies with no matching filings, empty searches and duplicates are free

The SEC publishes every filing for free, but the EDGAR website shows one company at a time, the JSON APIs need a CIK instead of a ticker, and full-text search is a separate service with its own format. Building a watchlist feed of 8-Ks or a table of the last two years of 10-Qs for 50 companies means stitching all of that together.

This guide shows how to get one clean row per filing from the official SEC EDGAR APIs: company, CIK, form, filing and report date, accession number, 8-K items as a list, SIC industry, and direct links to the main document and the filing index. The same run can also search the full text of every filing since 2001 for phrases like "going concern" or "cybersecurity incident". No API key is needed.

Open SEC EDGAR Filings Scraper on Apify →

Steps

  1. Add tickers (AAPL, BRK-B) or CIKs to companies. Tickers are resolved with the SEC's own ticker list, and unknown ones come back as free rows.
  2. Pick formTypes (empty means all forms) and an optional dateFrom. Turn on older filings if you need history beyond the latest ~1,000 filings per company.
  3. For a topic search, set fullTextQuery (e.g. "supply chain" tariff) with form and date filters instead of, or next to, companies.
  4. Run it and export as CSV or Excel. For a daily feed of new filings for your watchlist, add a Schedule with dateFrom set to yesterday.

Run it from code

Python

from apify_client import ApifyClient  # pip install apify-client

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run_input = {
  "companies": [
    "AAPL",
    "MSFT",
    "NVDA"
  ],
  "formTypes": [
    "10-K",
    "10-Q"
  ],
  "dateFrom": "2024-10-01",
  "maxFilingsPerCompany": 20

for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

FAQ

Does the SEC have a free API for EDGAR filings?

Yes. The SEC runs free JSON APIs on data.sec.gov and a full-text search service, with a fair-use limit of 10 requests per second and a declared User-Agent. This actor stays well under that limit and returns flat rows instead of raw JSON.

How do I get only earnings releases or executive changes from 8-K filings?

Set formTypes to ["8-K"] and filter the items column: 2.02 is results of operations (earnings), 5.02 is officer and director changes, 1.01 is a material agreement.

Can I feed the filings into an LLM or RAG pipeline?

Yes. Each row has documentUrl and filingIndexUrl, so you can fetch the main document or exhibits you need. The actor itself returns metadata and links, not the full documents.

What does it cost?

$0.0005 per filing returned ($0.50 per 1,000), cheaper on higher Apify plans. A filing found by two searches is charged once.
