How to scrape Apple App Store reviews for any app and country (CSV, JSON, API)

Updated 2026-10-09 · Tool used: Apple App Store Reviews Scraper - Ratings & App Data on Apify · Price: $0.08 per 1,000 reviews ($1 per 1,000 apps in app details mode); filtered and already-seen reviews are free

App Store Connect only shows reviews of your own apps, and the App Store website shows a handful per page. For competitor research, product feedback analysis or review monitoring you need the reviews of any app, per country, in a spreadsheet or JSON.

This guide shows how to pull reviews for any iPhone/iPad app by URL, ID or name, across one or many countries, filter them by stars, date or keywords, and schedule daily monitoring. It uses Apple's official public customer reviews feed and the iTunes Lookup API; reviewer names are not collected.

Open Apple App Store Reviews Scraper on Apify →

Steps

  1. Add apps as App Store URLs, numeric IDs or app names.
  2. Pick countries (e.g. us, gb, de or all) and the sort order (both = most recent + most helpful).
  3. Optionally keep only 1 to 2 star reviews, reviews since a date or reviews mentioning words like crash or subscription, then export to CSV or feed them to an LLM for sentiment analysis.

Run it from code

Python

from apify_client import ApifyClient  # pip install apify-client

client = ApifyClient("<YOUR_APIFY_TOKEN>")

  "apps": [
    "https://apps.apple.com/us/app/duolingo-language-lessons/id570060128",
    "Notion"
  ],
  "countries": [
    "us",
    "gb",
    "de"
  ],
  "sortBy": "both",
  "maxRating": 2,
  "reviewsSince": "2026-09-01"
}
run = client.actor("tinyrex/app-store-reviews-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

FAQ

Does Apple have an App Store reviews API?

Apple publishes a public customer reviews RSS/JSON feed per app and country. The actor uses it plus the iTunes Search/Lookup API, so there is no browser and no login.

How many reviews can I get per app?

Apple's feed returns up to 500 reviews per app, country and sort order. Combine both sort orders, several countries and a daily monitoring schedule to build a full history over time.

Is it GDPR-friendly?

Reviewer names and profile links are intentionally not collected, only the review content, rating, version and date.
