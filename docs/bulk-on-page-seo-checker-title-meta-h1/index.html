How to audit titles, meta descriptions, H1s and canonicals for hundreds of pages at once

Updated 2026-10-28 · Tool used: SEO On-Page Audit - Title Meta H1 Canonical OG Schema on Apify · Price: about $1.50 per 1,000 pages; unreachable pages are free

Browser SEO extensions check one page at a time, and desktop crawlers need a licence once a site has more than a few hundred URLs. For a quick content audit, a migration check or a competitor comparison you usually just want one row per page with the tags that matter and a list of what is wrong.

This guide shows how to audit any list of page URLs (pasted, from a sitemap export or from another actor's dataset) and get a table with title and description lengths, headings, canonical and hreflang, social tags, structured data types, link and image counts, word count and flags such as missing title, title too long >60 or multiple h1.

Open SEO On-Page Audit on Apify →

Steps

  1. Paste page URLs into startUrls, or pass dataset items that have a url field, for example the output of the sitemap URL extractor.
  2. Set maxUrls as a hard cap; robots.txt is respected by default.
  3. Export as CSV and sort by the issues column to see which pages need a new title, description, H1 or canonical first.

Run it from code

Python

from apify_client import ApifyClient  # pip install apify-client

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run_input = {
  "startUrls": [
    "https://example.com",
    "https://apify.com"
  ],
  "maxUrls": 100
}
run = client.actor("tinyrex/seo-on-page-audit").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript / Node.js

import { ApifyClient } from 'apify-client'; // npm i apify-client

});
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

curl (no SDK)

# Runs the actor and returns the results directly (CSV here; use format=json for JSON)
curl -X POST "https://api.apify.com/v2/acts/tinyrex~seo-on-page-audit/run-sync-get-dataset-items?format=csv" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"startUrls": ["https://example.com", "https://apify.com"], "maxUrls": 100}' > results.csv

FAQ

How do I check meta descriptions for all pages of a site?

Export the site's URLs from its sitemap (the sitemap URL extractor does this), then pass the list to this actor. Every row has metaDescription and its length.

Does it render JavaScript?

No. It reads the HTML the server returns, which is what most search engines index first. Pages that build their tags only in the browser will show those tags as missing.

Which issues are flagged?

Short flags such as missing title, title too long, missing meta description, multiple H1, missing canonical and images without alt text, so you can filter the sheet quickly.

Is it a full crawler?

No, it audits exactly the URLs you give it. Use the sitemap extractor or the broken link checker to discover URLs first.
