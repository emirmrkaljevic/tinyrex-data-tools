How to validate NPI numbers in bulk and build US healthcare provider lists from NPPES

Updated 2026-10-28 · Tool used: NPI Registry Lookup - Bulk NPI Search & Healthcare Providers on Apify · Price: $0.0008 per provider record ($0.80 per 1,000); invalid, unknown or deactivated NPIs, empty searches, filtered and duplicate providers are free

Every US healthcare provider that bills insurance has a 10-digit National Provider Identifier (NPI) in the NPPES registry run by CMS. Credentialing teams check NPIs, billing teams clean them up in claims data, and healthcare sales teams use the registry to find every practice of a given specialty in their territory. The public search page shows one provider at a time and caps results.

This guide shows how to use the free NPPES NPI Registry API in bulk: validate thousands of NPIs (the check digit is verified locally first), or build a provider list by specialty and location with flat spreadsheet columns for name, credential, primary specialty, license, practice address and phone.

Open NPI Registry Lookup on Apify →

Steps

  1. To validate or enrich, paste NPI numbers into npis, one per line. Numbers with a wrong check digit, unknown or deactivated NPIs come back as free found: false rows.
  2. To build a list, set taxonomyDescription (e.g. Dentist, Nurse Practitioner, cardio*) and combine it with cities, states or ZIP codes. Each city and state pair runs as its own search, up to the NPPES limit of 1,200 results per search.
  3. Turn on primaryTaxonomyOnly to keep real specialists (NPPES also matches secondary specialties), and set entityType to individuals or organizations.
  4. Run it and export the dataset as CSV or Excel, or send it to Google Sheets from the Integrations tab.

FAQ

Is there a free API for NPI lookups?

Yes. CMS runs the NPPES NPI Registry API with no key. The data is public by law (FOIA-disclosable), free to reuse, and US government work. This actor adds check-digit validation, paging, deduplication and flat columns.

How do I get a list of all dentists or pharmacies in a ZIP code?

Set the specialty and the ZIP codes, or use a raw NPPES search with taxonomy_description and postal_code. For a whole state, split by city or ZIP, since NPPES returns at most 1,200 providers per search.

Does an active NPI prove a provider is licensed?

No. An NPI is an identifier, not a license check. Use the license number and state in the output to verify with the state board.

What does it cost?

$0.0008 per provider found ($0.80 per 1,000). Rows with found: false, filtered-out providers and duplicates are not charged.
