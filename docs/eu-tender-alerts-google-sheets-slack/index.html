How to get daily alerts for new EU public tenders (TED) by CPV code and country

Updated 2026-10-09 · Tool: TED EU Tenders Scraper - Public Procurement & Awards · $2.50 per 1,000 notices; already-seen notices in alert mode are free

Paid tender alert services cost hundreds of euros per year, yet the underlying data, TED (Tenders Electronic Daily), is the EU's official open data. With a scheduled run you get only new notices that match your CPV codes, countries and keywords.

This tutorial sets up a daily alert in about five minutes.

Open the tool on Apify →

Step by step

  1. Open the TED Tenders Scraper and set your CPV codes (e.g. 72000000 for IT services), buyer countries and optional keywords.
  2. Turn on the only new notices mode so each run returns only notices you have not seen.
  3. Create a daily Schedule, then add an integration: Google Sheets, email or Slack (Integrations tab of the actor or task).
  4. To get the rows into Google Sheets: download the run's dataset as CSV and import it, or, for automatic updates, add an integration on the actor's Integrations tab (Apify's Google Sheets Import & Export actor, Make, Zapier or n8n) so every finished run appends its rows to your sheet.
  5. Alternatively, in Google Sheets use =IMPORTDATA("https://api.apify.com/v2/acts/tinyrex~ted-tenders-scraper/runs/last/dataset/items?format=csv&status=SUCCEEDED&token=YOUR_TOKEN"). Anyone with edit access to the sheet can see the token, so only do this in private sheets (or use a scoped token).
  6. Add a Schedule in Apify (daily or weekly) so the sheet stays fresh.

Example input

{
  "cpvCodes": [
    "72000000"
  ],
  "countries": [
    "DE",
    "AT"
  ],
  "publishedWithinDays": 1,
  "onlyNew": true
}

Same thing from the command line (returns CSV directly):

curl -X POST 'https://api.apify.com/v2/acts/tinyrex~ted-tenders-scraper/run-sync-get-dataset-items?format=csv' -H 'Authorization: Bearer $APIFY_TOKEN' -H 'Content-Type: application/json' -d '{"cpvCodes": ["72000000"], "countries": ["DE", "AT"], "publishedWithinDays": 1, "onlyNew": true}' > results.csv

FAQ

Is TED data free to reuse?

Yes, TED is official EU open data published by the Publications Office of the EU and may be reused, including commercially, with attribution.

What is a CPV code?

The EU's Common Procurement Vocabulary: an 8-digit code for what is being bought, e.g. 45000000 construction work or 72000000 IT services.
