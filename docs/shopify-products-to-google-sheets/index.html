How to get any Shopify store's products into Google Sheets (and keep prices updated)

Updated 2026-10-09 · Tool: Shopify Products Scraper - Prices, Variants, Stock & Monitoring · $0.70 per 1,000 products (+$0.50 per 1,000 for optional stock details)

Competitor price tracking, dropshipping research and catalog migrations all start with the same table: every product of a Shopify store with its variants, SKUs, prices, compare-at prices and stock. Copying it by hand stops working after 20 products.

Most Shopify stores expose their public catalog in a structured way, so you can get the whole catalog in seconds without a browser. Here is how to get it into a spreadsheet and keep it updated.

Open the tool on Apify →

Step by step

  1. Open the Shopify Products Scraper, paste one or more store URLs into stores and run it.
  2. To get the rows into Google Sheets: download the run's dataset as CSV and import it, or, for automatic updates, add an integration on the actor's Integrations tab (Apify's Google Sheets Import & Export actor, Make, Zapier or n8n) so every finished run appends its rows to your sheet.
  3. Alternatively, in Google Sheets use =IMPORTDATA("https://api.apify.com/v2/acts/tinyrex~shopify-products-scraper/runs/last/dataset/items?format=csv&status=SUCCEEDED&token=YOUR_TOKEN"). Anyone with edit access to the sheet can see the token, so only do this in private sheets (or use a scoped token).
  4. Add a Schedule in Apify (daily or weekly) so the sheet stays fresh.
  5. To track price changes, turn on the monitoring option so each run only returns changed products.

Example input

{
  "stores": [
    "https://www.allbirds.com"
  ],
  "maxProductsPerStore": 500
}

Same thing from the command line (returns CSV directly):

curl -X POST 'https://api.apify.com/v2/acts/tinyrex~shopify-products-scraper/run-sync-get-dataset-items?format=csv' -H 'Authorization: Bearer $APIFY_TOKEN' -H 'Content-Type: application/json' -d '{"stores": ["https://www.allbirds.com"], "maxProductsPerStore": 500}' > results.csv

FAQ

Does this need access to the store's admin?

No. It only reads the public catalog that any visitor can see.

Can I get one row per variant?

Yes, every variant (size, color) with its own SKU, price and availability is included.
