How to transcribe hundreds of audio and video files to text and subtitles with Whisper

Updated 2026-10-28 · Tool used: Audio & Video Transcriber (Whisper) - MP3/MP4 to Text, SRT, VTT on Apify · Price: $0.005 per audio minute with the base model, $0.01 with the small model; dead links, web pages, files without audio and silent files are free

Transcribing one file is easy with any app. Transcribing a whole podcast back catalogue, a folder of interview recordings or a batch of course videos is where per-seat transcription tools get expensive and slow, and uploading every file by hand does not scale.

This guide shows how to pass a list of direct audio or video links (or another run's dataset, for example podcast episode enclosures from an RSS feed) and get one row per file: full text, detected language, timestamped segments and ready-made .srt and .vtt subtitle files. It runs the open-source Whisper model (faster-whisper) inside the actor, so there is no OpenAI key and the audio is not sent to an outside speech service.

Open Audio & Video Transcriber (Whisper) on Apify →

Steps

  1. Collect direct file links in mediaUrls (podcast MP3 links, files in cloud storage, CDN links), or set datasetId to read links from another actor run.
  2. Pick model: base is fast and cheap, small is better on accents, noise and non-English. Set language if you know it, or task: "translate" for an English transcript of any language.
  3. Run it, export the dataset as CSV or JSON, and download subtitles from srtUrl / vttUrl. Set a max charge per run to cap the cost.

Pricing

Pay per result: $0.005 per audio minute with the base model, $0.01 with the small model; dead links, web pages, files without audio and silent files are free. You can cap the cost of every run in the run options.

FAQ

Can I transcribe podcast episodes straight from an RSS feed?

Yes. Run the RSS Feed Scraper on the podcast feed, then pass its run's datasetId and set urlField to the enclosure field. Each episode's audio link is transcribed.

Which languages are supported?

Whisper supports about 99 languages. Leave language on auto to detect it, or set it for better accuracy on short files.

Is this a cheaper alternative to the Whisper API?

It runs the same open-source Whisper model family inside the actor for $0.005 per audio minute (base) or $0.01 (small), billed per minute rounded up per file. Failed and silent files cost nothing, and there is no separate API account.

Can I transcribe YouTube, TikTok or Instagram videos?

No. Links to platform pages are refused for free, because downloading from those sites is against their terms. Use files you own or have rights to, such as your own recordings or podcast MP3s.

Does it add speaker labels?

Not yet. You get timestamped segments and subtitles, without speaker diarization.

How fast is it?

At the default memory the base model handles about 10 to 12 minutes of audio per minute, the small model about 4. More memory gives more CPU cores; the price per audio minute stays the same.
