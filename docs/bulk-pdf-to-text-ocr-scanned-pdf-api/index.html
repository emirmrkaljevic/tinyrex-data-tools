How to extract text from hundreds of PDFs, including scanned ones, in one run

Updated 2026-10-27 · Tool used: PDF Text Extractor & OCR - Bulk PDF and Image to Text on Apify · Price: $1.50 per 1,000 PDFs + $0.002 per OCR page; failed downloads, non-PDF links, password-protected files and blank pages are free

Reports, invoices, tender documents and archives usually arrive as a pile of PDFs, and some of them are scans with no selectable text at all. Online converters handle one file at a time, and sending every page through a paid OCR API is wasteful when most PDFs already contain exact text.

This guide shows how to pass a list of PDF or image links and get one row per file with the full text, page count and the method used. Digital PDFs are read from their text layer (fast, no OCR errors) and only pages without text go through Tesseract OCR, so you only pay the OCR price where it was needed. Everything runs inside the actor, with no outside OCR service.

Open PDF Text Extractor & OCR on Apify →

Steps

  1. Add direct links to fileUrls, or set datasetId to collect PDF and image links from another run (for example a sitemap export filtered to .pdf).
  2. Leave ocrMode on auto and choose languages for non-English scans. Turn on includePages if you want per-page text for RAG chunking and page citations.
  3. Run it and export the dataset as JSON or CSV, or load it straight into LangChain, LlamaIndex or a vector database.

FAQ

How do I extract text from a scanned PDF?

Add its link and keep OCR mode on auto. Pages without a text layer are rendered and read by Tesseract; the row shows method: ocr and the number of ocrPages.

How can I tell if a PDF is scanned or has real text?

Each row reports textLayerPages, ocrPages and a method of text-layer, ocr or mixed.

Does it work on images like PNG or JPG?

Yes. PNG, JPEG, TIFF, WebP, GIF and BMP links are OCR'd as one page each.

Are my documents sent to a third-party API?

No. Download, text extraction (poppler) and OCR (Tesseract) all run inside the actor's container, and results stay in your own Apify storage.
