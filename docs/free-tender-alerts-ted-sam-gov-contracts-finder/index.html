How to get EU, US and UK tender alerts in one Google Sheet (TED, SAM.gov, Contracts Finder)

Updated 2026-10-27 · Tool: SAM.gov & UK Contracts Finder Tenders Scraper · $2.50 per 1,000 notices; empty or failed runs and notices skipped as already seen are free

If you sell to governments in more than one market, you end up checking three portals every morning: TED for the EU, SAM.gov for US federal buyers and Contracts Finder for the UK. Commercial tender alert services that cover all three usually cost hundreds per year, yet all three sources publish official open APIs.

This tutorial sets up two scheduled runs, one for TED and one for SAM.gov plus Contracts Finder, that return only new notices matching your keywords and append them to the same Google Sheet. Both tools share the core columns (noticeId, title, buyerName, buyerCountry, publicationDate, deadlineDate, isOpen, estimatedValue, procedureType, noticeUrl), so the sheet reads as one list.

Step by step

  1. US and UK: open the SAM.gov & UK Contracts Finder Tenders Scraper, select both sources, paste your free SAM.gov public API key (Account Details on sam.gov) and add your keywords. Contracts Finder alone works without any key.
  2. EU: open the TED Tenders Scraper with the same keywords, plus CPV codes (e.g. 72000000 for IT services) and buyer countries if you want to narrow it. Example: {"keywords": ["cybersecurity"], "cpvCodes": ["72000000"], "publishedWithinDays": 1, "onlyNew": true, "stateKey": "cyber-eu"}.
  3. In both, turn on onlyNew and give each saved search its own stateKey, so every run returns only notices you have not seen yet (skipped notices are free). Save each input as a task and add a daily Schedule.
  4. On each task's Integrations tab, append the rows to the same Google Sheet (Apify's Google Sheets Import & Export actor, Make, Zapier or n8n). Map TED's estimatedValueCurrency to the currency column; the other core columns have the same names. Add a Slack or email step if you want a ping when new rows arrive.
  5. To get the rows into Google Sheets: download the run's dataset as CSV and import it, or, for automatic updates, add an integration on the actor's Integrations tab (Apify's Google Sheets Import & Export actor, Make, Zapier or n8n) so every finished run appends its rows to your sheet.
  6. Alternatively, in Google Sheets use =IMPORTDATA("https://api.apify.com/v2/acts/tinyrex~us-uk-tenders-scraper/runs/last/dataset/items?format=csv&status=SUCCEEDED&token=YOUR_TOKEN"). Anyone with edit access to the sheet can see the token, so only do this in private sheets (or use a scoped token).
  7. Add a Schedule in Apify (daily or weekly) so the sheet stays fresh.

FAQ

Are TED, SAM.gov and Contracts Finder data free to reuse?

Yes. TED is EU open data from the Publications Office of the EU, reusable with attribution. Contracts Finder is published under the UK Open Government Licence v3.0. SAM.gov opportunity data is US government information; you only need a free public API key to call the API.

Do I need a SAM.gov API key?

Only for the US source. Create a free SAM.gov account, open Account Details and generate a public API key. TED and Contracts Finder need no key.

What does a daily three-market alert cost?

Both tools charge $0.0025 per new notice ($2.50 per 1,000). A focused keyword search typically returns a few dozen new notices a day, so a month of alerts usually stays within the free monthly credit of the Apify free plan. Runs that find nothing new cost only the start fee.

Can I filter by CPV or NAICS code instead of keywords?

Yes. TED takes CPV codes (with sub-codes included by default), SAM.gov takes a NAICS code, and UK notices carry their CPV code in cpvOrNaics, so you can also filter in the sheet.
